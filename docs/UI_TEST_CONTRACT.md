# UIテスト契約（最小SwiftUI shell）

この文書は、L01相当の最小shellに対するXCUITestの先行契約です。製品ViewやXcodeプロジェクトが未実装の段階でも、画面の入口と遷移を後続実装が同じ識別子で提供できるようにします。

## 対象範囲

`MapGrapherIOSUITests/LaunchUITests.swift` は、次の3点だけを検証します。

- `XCUIApplication` が `app.launchArguments = ["--ui-testing"]` で起動できること
- 日本語の4タブ（地図、グループ、お知らせ、マイページ）を相互に選択できること
- 地図から「AR動作確認」を押すと、専用のAR試作画面へ遷移すること

このテストは、地図API、Supabase Auth、実ユーザー、実データ、位置情報、ARKitのセッション成立を検証しません。UI専用の起動経路は認証やネットワークの成否に依存させず、shellの表示と画面遷移だけを確認できるようにします。

## 起動契約

アプリはXCUITestの起動時に次を受け取り、UIテスト用の決定的なshellを表示します。

```swift
app.launchArguments = ["--ui-testing"]
app.launch()
```

起動直後の選択タブは「地図」です。テスト用経路でログイン済み状態やAPI疎通を偽装したことを、実認証・実通信の完了として扱いません。

## 識別子とラベル

画面とボタンの識別子は表示文言から独立した契約値です。画面識別子は各画面のルート要素へ設定し、ルート要素のアクセシビリティラベルを表の値に揃えます。標準SwiftUI `TabView`のタブは、iOS 18.5 Simulator / Xcode 16.4の実測で`tabItem`内の独自`accessibilityIdentifier`が実際の`UITabBarButton`へ安定して伝播しないため、独自identifierを契約しません。XCUITestは標準タブバーbuttonの日本語ラベルで取得します。

| 種別 | `accessibilityIdentifier` | 必須アクセシビリティラベル | 意味 |
| --- | --- | --- | --- |
| タブ | 固定しない（標準`TabView`） | `地図` | 日本語ラベルで取得。起動時に選択 |
| タブ | 固定しない（標準`TabView`） | `グループ` | 日本語ラベルで取得 |
| タブ | 固定しない（標準`TabView`） | `お知らせ` | 日本語ラベルで取得 |
| タブ | 固定しない（標準`TabView`） | `マイページ` | 日本語ラベルで取得 |
| 画面 | `screen.map` | `地図` | 地図画面のルート要素 |
| 画面 | `screen.groups` | `グループ` | グループ画面のルート要素 |
| 画面 | `screen.notifications` | `お知らせ` | お知らせ画面のルート要素 |
| 画面 | `screen.profile` | `マイページ` | マイページ画面のルート要素 |
| 画面 | `screen.ar-preview` | `AR試作` | AR試作画面のルート要素 |
| ボタン | `map.ar-preview.button` | `AR動作確認` | 地図からAR試作画面を開く |

タブを選択したときは対応する画面ルートが表示され、選択中のタブ項目はXCTestから選択状態として取得できることを求めます。AR試作画面は、ARKitの実装やカメラ権限をこの契約の前提にしません。

## テストと実装の境界

この契約で扱うのは、画面が存在し、識別可能で、日本語のラベルを持ち、指定された操作で遷移することだけです。認証フロー、地図の取得・表示、Storage、位置ゲート、AR平面検出、アンカー配置は各機能の実装と検証で別途扱います。
